# 数字溯源对照表 v1.37

稿件：*The resolution of a comparison depends on how correlated the two scores are:
equivalence analysis of five biological age indices in 34,393 US adults and audit of
22 head-to-head comparisons*（Manuscript v1.37，目标刊 The Lancet Healthy Longevity）
建表日期：2026-11-05
配套：`结果表\` 下全部 CSV 由 `代码\` 下脚本生成；本表给出"稿件每个数字 → 哪个 CSV → 哪个脚本 → 哪一段代码"。

运行方式（一键复现）：

```
powershell -File 代码\rebuild_all.ps1
```

顺序：`build_ext` → `build_ext_cyc` → `run_ext` → `run_ext_extra` → `run_ext_tail2` → `build_ext10` → `build_ext_cyc10` → `run_x10`
→ `代码\_v136\a_validate_baseline.py` → `b2_cluster_bootstrap_grid.py` → `c_resolution_empirical.py`
→ `d_exposure_heterogeneity.py` → `e_figures.py`。

> **口径声明**：正文与表 2 的 C 指数是**未加权 Harrell C**（`cindex_hr.csv`，来自未加权 Cox 拟合）；
> 加权 HR 来自 `weighted_hr.csv`（WTMEC2YR + PSU 聚类）。两者不可混标。
> ΔC 的区间来自 **删一 PSU jackknife**（240 个聚类，`结果表\_v136\jackknife_equivalence.csv`，脚本 `代码\_v137\jackknife_g4.py`）；cluster bootstrap（1,000 次，种子 20261105）作为敏感性分析并列报告；
> 仍不含调查权重，此点在正文局限中已声明。

## 溯源规则（自检用）

1. 稿件里出现的任何数值，必须能在上表找到对应 CSV 与脚本；找不到的即为**无源数字**，不得投稿。
2. 若脚本重跑后数值变动，先改结果表，再改稿件，并在稿件头部登记版本变更。
3. 本表与 `结果表\` 同时冻结；投稿前对 `结果表\` 生成 SHA-256 清单（见 `哈希清单_v1.37.txt`）。
